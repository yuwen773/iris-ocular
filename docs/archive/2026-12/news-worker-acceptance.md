## 离线资源

Windows、Python 3.12.12。每个场景启动新的测量进程，运行一个执行槽。CPU 和墙钟时间从模拟环境装配起计量，峰值为操作系统报告的整个进程工作集，包含 Mock Java 和夹具。仿真禁用外部限速等待，重试保留退避。启动场景测量进程内的客户端初始化至无任务退出。

| 场景 | 墙钟秒 | CPU 秒 | 峰值 MiB | 信源请求 | 控制面请求 | 完成的修订 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 启动与空闲领取 | 0.5265 | 0.3125 | 59.75 | 0 | 1 | 0 |
| 两页增量 | 1.0912 | 0.1406 | 52.61 | 2 | 4 | 2 |
| 80 页密集窗口 | 0.9660 | 0.7969 | 66.05 | 80 | 82 | 4,000 |
| 连续 429、503、503 | 0.9689 | 0.1406 | 52.16 | 3 | 2 | 0 |

密集窗口的离线峰值低于 256 MiB 设计目标。受限 CPU 下实际采集吞吐、云主机内存及 Java 和眼底推理 P95 影响仍为 `NOT_RUN`。

## 真实信源样本

真实采集请求为零。授权后每个信源先核对一个显式小窗口，包括 API 字段、身份、日期、分页结束条件、请求数及保留许可，再决定是否启用。

| 信源 | 状态 | 首次实测需确认 |
| --- | --- | --- |
| PubMed | `NOT_RUN` | 创建日与修订日组合、History 分页记录数、日期精度、联系邮箱和工具标识。 |
| Europe PMC | `NOT_RUN` | 空窗与最终游标形态、源内更新日、公开摘要的许可字段。 |
| ClinicalTrials.gov | `NOT_RUN` | 更新发布日期范围、投影字段、NCT ID 及最终页令牌。 |

后续门槛见 [实施决策与 Java 交接](../../product/news/implementation.md)。
