# WP-07 · 资讯采集灰度验收

验收日期为 2026-11-25，基线为 `e0dabebf`。本次使用 Windows 工作站、隔离的 Spring Boot `ci` 实例及临时 MySQL 8、Redis 7 和 Chroma 容器。模型精选保持关闭，实测只涉及眼科资讯采集。

## 信源结果

| 信源 | 已取得的证据 | 正式 Worker 实采状态 |
| --- | --- | --- |
| PubMed | 使用已提供的联系邮箱，对 `myopia[Title]` 的 2025-10-06 创建日或修订日窗口发起 2 次官方请求。ESearch 返回 HTTP 200、7 条记录及 History 参数。EFetch 返回 HTTP 200，完整取回 7 条，全部通过现有投影，均有 PMID 及修订日期，保留摘要 0 条。 | `BLOCKED_ENV`，已通过独立 HTTP 与字段探针 |
| Europe PMC | 使用 `TITLE_ABS:myopia AND SRC:MED` 探查 2025-10-06 的更新窗口。官方 API 的 1 次 GET 超时，未收到响应或记录。另有 1 次 HEAD 连通性检查超时。 | `BLOCKED_ENV` |
| ClinicalTrials.gov | 4 次官方查询均返回 HTTP 200。三日窗口验证空集且无下一页。10 月窗口两页各 5 条并带下一页令牌，按预定上限停止。另一个五日窗口返回 1 条且无下一页。11 条记录均通过现有投影校验，NCT ID 与更新日期可读，更新日期均在各自窗口内。 | `BLOCKED_ENV`，已完成独立 HTTP 与字段探针 |

独立 HTTP 探针通过系统网络路径访问官方 API。Windows、WSL 和 Docker 的 DNS 检查均发现受影响信源被解析到 `198.18.0.0/15` 保留地址段。正式 Worker 的公网地址验证会在发送请求前返回 `SOURCE_BLOCKED`。保持现有地址校验，在具有正常公网 DNS 和校验通过的 HTTPS 路径的灰度环境重跑。

## 数据使用边界

- **PubMed** 保留题录字段，当前投影省略摘要。按 E-utilities 要求配置可联系邮箱及工具标识，并在对外展示前核对 NCBI 声明和具体权利。 [NCBI 接入与版权规则](https://www.ncbi.nlm.nih.gov/books/NBK25497/?report=printable)
- **Europe PMC** 当前投影只在识别到允许的 CC BY 或 CC0 许可时保留摘要。灰度样本尚未验证许可字段。启用摘要前核对实际文章的许可声明，记录归属和许可口径。 [Europe PMC 版权要求](https://dev.europepmc.org/Copyright)
- **ClinicalTrials.gov** 本次投影仅使用 NCT ID、标题、发布日期、更新发布日期及试验结构。对外分发前还需验证显示信源归属、数据处理日期、内容修改说明及更新处理。 [ClinicalTrials.gov 使用条款](https://clinicaltrials.gov/terms-conditions)

## 隔离控制面与资源

- 未携带机器凭证的领任务请求收到 HTTP 401。正式 CLI 分别领到 Europe PMC 和 ClinicalTrials.gov 的隔离窗口，两次都上报 `SOURCE_BLOCKED`。MySQL 中任务均为 `FAILED`、代次和尝试次数均为 1，游标仍为 2025-10-06，零可见资料修订，零公开资讯。随后一次领取返回空闲。
- 将五日窗口取得的 ClinicalTrials.gov 原始响应作为离线输入，经现有适配器和 Worker 重放至同一隔离 Spring 实例。真实控制面依次接收领任务、批次、完成共 3 次请求。MySQL 确认任务 `COMPLETED`、1 条资料修订可见，游标从 2025-10-09 推进至排他上界 2025-10-14，公开资讯仍为零。重放测得峰值工作集 52.46 MiB，墙钟 0.125 秒，CPU 0.0312 秒。该读数未包含信源网络请求，临时容器、卷和网络已回收。
- 32 项 Worker 离线测试通过。4,000 条离线仿真峰值工作集 65.48 MiB，墙钟 0.2999 秒，CPU 0.2969 秒。工作集包含测试进程内的模拟器，具有本机基线意义。
- WSL 本地验证 `flock -n -E 75`。同一锁已被占用时第二次执行返回 75，释放后再次执行返回 0。

## 目标环境的剩余验收

在目标环境先确定一个执行调度入口。若为单台 Linux 主机，复用同一个稳定锁路径，以非阻塞方式串行执行 `run-once`。按首轮资源口径限制 Worker 为 0.5 CPU、256 MiB，用单执行槽和显式秒数预算验证超时退出、重叠时不领取任务以及下一轮可启动。在多主机部署中，互斥证据须覆盖不同主机的重叠触发。

每次只给测试 Worker 授权一个信源，投递显式小窗口。记录请求量、终止条件、有效修订、失败回执、游标及资源峰值。通过灰度验收后再逐源决定是否启用。

P95 使用同一目标主机、相同负载、相同预热方式和固定样本做两组对照，一组关闭采集，一组采集运行中。分别记录 Java 请求与眼底推理耗时的 P95、样本数、错误率和 Worker 资源数据。使用目标环境已有的性能门槛，门槛缺失时保留实测结果待判定。目标环境和压测结果目前为 `NOT_RUN`。付费模型联调须另行授权与明确调用上限。
